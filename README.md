# wdd131

Course work for **WDD 131 – Dynamic Web Fundamentals** (BYU–Pathway Worldwide).

## Week 01 – Home Page

The course landing page: semantic HTML, an external `styles/base.css`
(Flexbox navigation, CSS Grid card layout, Google Fonts), and
`scripts/getdates.js`, which dynamically writes the current copyright year
and the document's last‑modified date into the footer.

Published with GitHub Pages: <https://KenDevDash.github.io/wdd131>
